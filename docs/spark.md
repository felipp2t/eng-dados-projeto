# Apache Spark

## O que é
O Apache Spark é um framework de processamento de dados distribuído, utilizado para trabalhar com grandes volumes de dados de forma rápida e eficiente.

## Principais características
- Processamento distribuído
- Alta performance
- Suporte a múltiplas linguagens (Python, Java, Scala)
- Integração com diversas ferramentas de Big Data

## PySpark
Neste projeto foi utilizado o PySpark, que é a API do Apache Spark para Python.

## Uso no projeto
O Spark foi utilizado para:
- Criar tabelas
- Inserir dados
- Atualizar dados
- Remover dados

Servindo como base para o uso do Delta Lake e Apache Iceberg.
