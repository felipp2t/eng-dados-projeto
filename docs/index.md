# Projeto de Engenharia de Dados

## Apache Spark com Delta Lake e Apache Iceberg

Este projeto demonstra o uso do Apache Spark com Delta Lake e Apache Iceberg para manipulação de dados.

## Objetivo
Demonstrar operações de:
- INSERT
- UPDATE
- DELETE

Utilizando tecnologias modernas de processamento de dados.

## Tecnologias
- Apache Spark
- Delta Lake
- Apache Iceberg
- Docker
- Jupyter Notebook
